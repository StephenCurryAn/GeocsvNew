## 实现和边界

- 左右分隔线调节栏宽，横向分隔线调节地图与属性表高度。方向键每次移动 8 像素，Shift 加方向键移动 32 像素，Home 和 End 跳至最小及最大尺寸。拖拽和键盘使用同一组约束。两侧最小宽度为 178 和 264 像素，中央最小宽度为 300 像素，地图区和属性表区最小高度为 240 和 218 像素。小于布局最小尺寸的视口可滚动浏览工作台。页面分栏尺寸在本次打开期间保留。
- Ant Design 与工作台 CSS 变量随主题更新。首次打开使用浅色，工作空间顶栏可切换深色和跟随系统，选择在当前浏览器持久化。底图由原有控制器管理，可独立切换。
- 图例沿用文件 ID。可单独隐藏或显示图层，切换活动文件时仍保留已选文件的显隐状态。空数据、数据读取错误、额外 GeoJSON 图层读取错误与瓦片错误有行内提示。移除失效的地图源会同步清理要素弹窗，分析结果继续由原有状态与历史管理。
- 属性表保留分页与横向、纵向滚动。当前页要素支持表格到地图定位和地图到表格选择。地图按现有接口绘制超出表格当前页的要素，跨页自动跳转暂无按要素查页的能力。
- 右栏直接显示「空间分析助手」。保留现有自然语言算子流程、实验流程、分析历史、草稿与运行结果。主题同时适配工具面板、地图图例与要素弹窗、表格浮层和分析结果窗口。

08 的资源组件、上传参数和资源归属由原模块负责。工作台通过既有 LeftPanel 属性取得已选文件和活动文件。合入时由主会话接入活动场景的文件选择和助手上下文。LangGraph、阶段 5 的专业模型入口按实施计划后接。此分支涉及的分析组件变更仅限样式和已有组件的主题继承。

## 验证

- 鼠标拖动左、右、中央三个分隔线后，分别核对栏宽、表高和地图画布像素尺寸。1024 像素视口下，使用键盘调整至边界，中央仍保有 300 像素宽度和 240 像素地图区高度。检查助手保持可见，实验流程草稿可在模式间恢复。
- 改变布局后，检查属性表双向滚动、表格点击定位、地图点击选中并滚动到当前页对应行。切换 CARTO 浅色和深色后检查业务源身份、相机和选中弹窗。在地图缩放、图层显隐、主次图层切换和取消选择时检查业务图层与历史结果。
- 检查多个选中图层、空文件、分页数据加载错误、额外 GeoJSON 请求失败与 MVT 请求失败。不依赖远端底图供应商或真实业务文件复现这些分支。
- 浅色、深色和跟随系统分别检查页面刷新。系统配色变化时，跟随系统即时更新工作台主题。
- 前端已有测试使用 npm run test:basemaps、npm run test:analysis 和 npm run test:pipeline，共 18 项。npm run build 完成 TypeScript 检查和生产打包。Vite 提示部分打包文件超过 500 kB。

## 空间透视结果复查

参考本地留存的 [NeoGIS Tenon 主题](https://github.com/GeoScenarioScripter/NeoGIS-Frontend/blob/1920529834d1afe153467c1df7ce410c9f7a5825/docs/themes/tenon.md)，结果窗口用暖浅色、石墨深色、柔和边界和短过渡。首屏左侧为结果地图，右侧为图表和明细，顶部是结果摘要和 CSV 导出。窄窗口下分区改为纵向排列，各区仍可操作。

结果图用低饱和底图辅助辨认位置，专题数据可独立绘制。地图、图表、明细通过要素 ID 联动，选中统一为暖色。选择变化沿用当前地图和缩放，只有要素在视口外才定位。保留全图定位、图表类型切换、分页和导出。支持键盘选中明细行和减少动态效果的系统设置。

生产预览用 Chrome 和合成数据验证表格、地图、图表双向联动，检查柱状、折线、占比切换、长图表滚动、明细分页、CSV 下载和空结果。核对 1440 × 900、1024 × 768 和 710 × 780 的布局。已有前端 18 项测试通过，生产构建完成。

## 整体主题与内嵌结果

暖白采用 NeoGIS Tenon 暖纸、细边框与低饱和蓝的方向，苔绿沿用相同结构，采用浅苔与暗林配色。两套主题分别支持浅色、深色、跟随系统，风格和明暗独立保存。资源面板、助手、地图工具与图例、属性表、提示浮层和结果图表继承同一套界面颜色。主地图底图可独立选择。

中央提供「工作地图」和「分析结果」。从左侧工具或右侧助手打开历史结果时，中央切换到结果页签，左右栏继续可用。往返时工作地图与结果地图各自保留相机和选中项。两处入口使用同一份运行历史，各自的任务、结果与预览状态由工作台持有。完成后台任务时不抢占当前页签。

用独立的 Chrome 生产预览和合成数据，核对两套主题的四种面貌、跟随系统即时切换及刷新恢复。验证两侧均可打开结果、键盘切换页签、地图与表格保留视角及选中、拖动侧栏后的结果布局、CSV 下载和减少动态效果。1024 像素下中央地图置顶，图表和明细在下方并排，更窄时纵向排列。
