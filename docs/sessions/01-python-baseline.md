## 检查与测试设计

- [`main.py`](../../python_engine/main.py) 中的空间自相关路由从 PostGIS 读取图层，按行展开属性，筛选面并尝试用 `buffer(0)` 修补无效面。字段经 `pd.to_numeric(errors="coerce")` 转换，删除空值、重置行索引，再构建邻接。局部结果按数据库要素 ID 返回，同时生成地图 GeoJSON。

## 独立手算

A 为 `[0,0]–[1,1]`，B 为 `[1,0]–[2,1]`，C 为 `[2,1]–[3,2]`，D 为 `[10,0]–[11,1]`。A 与 B 共边，B 与 C 只共点，D 孤立。按 A、B、C、D 的顺序，`queen` 的邻接表为 `[[1], [0,2], [1], []]`，`rook` 为 `[[1], [0], [], []]`。测试使用非连续索引核对这些数字是行位置。

取属性值 `[1,3,5,7]`，中心化为 `[-3,-1,1,3]`。按 `queen` 构造的行标准化矩阵为：

```text
W = [ 0    1    0    0 ]
    [ 1/2  0    1/2  0 ]
    [ 0    1    0    0 ]
    [ 0    0    0    0 ]
```

- 中心化值的空间滞后为 `[-1,-1,-1,0]`，点积为 3，离差平方和为 20。D 的值参与均值和离差平方和，权重行全为零，因此 `n=4`、`S0=3`，全局 I 为 `(4/3) × 3/20 = 1/5`，旧实现报告的随机期望为 `−1/3`。
- 各行乘积为 `[3,1,-1,0]`，除以总体二阶矩 `20/4=5` 后得到局部 I `[3/5,1/5,-1/5,0]`。API 的空间滞后列是标准化后的滞后，故预期为 `[-1,-1,-1,0]/√5`。浮点断言使用绝对容差 `1e-12`，路由结果按实际输出的六位小数检查。

### 固定种子的四次置换

用锁定的 NumPy 单独置换四个位置，记录种子 42 的前四个抽样顺序。设置换后 A、B、C 的中心化值为 `a,b,c`。按上面的路径，双向边合计的全局 I 为 `b(a+c)/10`。旧局部检验固定原焦点值，只替换滞后，所以四个局部统计量分别为 `−3b/5, −(a+c)/10, b/5, 0`。

| 中心化值分配到 A、B、C、D | 全局 I | 旧局部置换 I |
| --- | --- | --- |
| `[3,1,-1,-3]` | `1/5` | `[-3/5,-1/5,1/5,0]` |
| `[3,1,-3,-1]` | `0` | `[-3/5,0,1/5,0]` |
| `[-3,3,1,-1]` | `-3/5` | `[-9/5,1/5,3/5,0]` |
| `[1,3,-3,-1]` | `-3/5` | `[-9/5,1/5,3/5,0]` |

以零为中心比较绝对值并计入并列，四次有三次达到全局观测值的极端程度，加一校正得到 `p=4/5`。四个全局置换值均值为 `−1/4`、总体标准差为 `√51/20`，得到 `z=9/√51`。各行达到局部阈值的次数依次为 `[4,3,4,4]`，得到局部 p 值 `[1,4/5,1,1]`。置换数为 0 时，全局和局部 p 值均为 1，全局 z 为空。

## 边界行为

| 输入 | 离线实测 |
| --- | --- |
| 个别要素缺少属性键、空值、非法字符串 | 逐行删除。数字字符串 `"5"` 数值化后保留。相邻方格链删去缺失行后，只留下原位置 0、2、3，邻居数为 `[0,1,1]`。独立手算以 `[-10,2,8]/3` 为中心化值，唯一邻接对的双向乘积为 `32/9`，全局 I 为 `(3/2) × 32/168 = 2/7`，局部 I 为 `[0,2/7,2/7]`，标签为一条孤立街道、两条不显著。 |
| 清洗后不足 3 条 | 路由抛出 400，详情提示可用于分析的数量不足。 |
| 常量、正无穷或负无穷 | 常量离差平方和为零。无穷通过 `dropna`，使离差平方和非有限。三种输入均抛出 500，详情提示数值离散性不足。 |
| 所有要素孤立 | 权重和为零，路由抛出 500。部分孤立时保留要素，其局部 I 和滞后为零，p 值为 1，路由标为“孤立街道”。 |

## 科学语义与下一批

1. **先确定清洗规则和有效权重。** 将有限数值校验、删行数量、常量及全孤岛的领域错误写入算子契约。约定缺失 CRS、几何修补、重叠与包含的处理方式。libpysal 文档按共享顶点和共享边定义 Queen 和 Rook。等到锁定版本后，应用同一套几何比较其邻接结果，单独覆盖跨边界接点、重叠与包含。[libpysal Queen](https://pysal.org/libpysal/stable/generated/libpysal.weights.Queen.html) · [libpysal Rook](https://pysal.org/libpysal/stable/generated/libpysal.weights.Rook.html)
2. **局部 I 与局部检验分别对照。** esda 2.9 的局部 I 分子乘 `n−1`，旧代码对应乘 `n`。相同权重与样本下，四面样例的 esda 局部 I 应为旧值的 `3/4`。旧局部置换会将焦点原值放进邻居候选，例如第一次置换中 C 的原值 `1` 落在邻居 B 上，同时仍作为 C 的焦点值。下一批用排除焦点的条件随机化做对照，并明确局部尾部、并列与多重检验规则。[esda 2.9 源码](https://pysal.org/esda/v2.9.0/_modules/esda/moran.html#Moran_Local) · [Moran_Local 2.9 文档](https://pysal.org/esda/v2.9.0/source/generated/esda.Moran_Local.html)
3. **单独选择全局推断规则。** 当前全局检验按距零的绝对值计尾，零假设的 I 期望在四面样例中为 `−1/3`。改用距该期望的距离时，同四次抽样只有首个并列值达到阈值，加一结果会成为 `2/5`。这说明尾部定义本身就会改变显著性。下一批先穷举小样例验证选定规则，再对齐参考库；同时固定要素 ID 顺序，当前 SQL 缺少 `ORDER BY`，固定种子只能在输入顺序固定时复现同一串模拟统计量。
4. **版本化后再接入统一任务。** 等主会话发布 Operator、Run 和 Artifact 契约，再登记有效参数、权重及孤岛策略、随机种子、输入快照和算法版本。对旧结果保留来源与解释。参考库对照及新统计定义属于下一批。
