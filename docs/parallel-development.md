## 场景与工作台并行改造

08 与 09 是现在可独立交付的工作，编号用于识别会话。阶段 5 基于两者接入已验收的 LangGraph 会话、分析结果和专业模型入口。

| 会话 | 分支 | 首批交付 |
| --- | --- | --- |
| 08 场景与资源管理 | `codex/08-scene-resources` | 创建和切换场景、场景内上传及文件夹、多图层选择、刷新恢复场景，旧资源迁入默认场景并保留文件 ID。 |
| 09 工作台布局与视觉 | `codex/09-workbench-ui` | 左侧工作空间、中央上方地图及下方表格、右侧固定助手，可拖拽分隔线，浅色与深色主题，修正可复现的图层状态问题。 |

**08** 负责场景数据结构、文件接口、资源树和场景选择器。场景是资源与分析上下文的边界。每个场景有自己的资源树，可包含多个图层。旧资源默认归入「默认场景」。验收至少创建两个场景、各上传资源、在其中一个同时选中两个图层。切换和刷新后资源、选中状态与地图应对应活动场景。禁止场景 A 的受场景约束接口修改场景 B 的节点。旧全局接口作为迁移路径记录其实际行为。

**09** 负责应用外壳、地图和表格分区、助手外观以及主题。三个区块以可拖拽分隔线调宽，地图与表格之间可调高度。地图上保留可用空间，拖动后验证地图尺寸更新和选中联动。助手固定占据右栏，图标改用简单的对话标记。浅色为默认，可切换深色或跟随系统。图层列表与图例需要有清楚的可见、加载、空和失败状态。验收包括宽屏、窄桌面、主题切换后刷新、拖动后地图和表格，以及多个图层加载与切换。

08 与 09 分别修改资源和布局，主会话负责把活动场景接入地图、表格选择及助手上下文。02 继续完成 Moran/LISA。Agent 默认使用活动场景，后端用可信的场景与数据集 ID 校验访问范围。单场景分析接入时一起校验 Run 与 Artifact 的归属。跨场景分析在单场景闭环验收后接入，由用户明确选择参与场景和数据，并记录输入来源。

此次合并在独立 PostGIS 测试库验证了 5 项集成测试。浏览器从有两个图层的场景切到空场景时，业务地图、图例和属性表全部清空。切回后恢复两个图层，刷新后仍能读到相应的属性行。

新阶段从包含已验收前置成果的整合提交创建分支，在 GeoCSV 项目下使用独立工作目录 `D:/GeoCSV/.worktrees/NN-english-module`。日常改动使用主会话现有工作区，按需验证。阶段会话提交成果并报告代码、学习要点和验收情况，主会话审阅后合入并更新依赖阶段。后置会话到达开始条件再创建。
