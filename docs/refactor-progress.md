# 首轮重构实施记录

## 范围与顺序

1. 修复文件缓存身份、地图重复加载、AI 流协议、旧透视字段参数化、重试终态和 Python 连接释放。
2. 增加独立的空间透视模块：数据目录、结构化计划、执行记录、不可变结果、结果分页和导出。
3. 在现有分析工具中接入行政区与分类 POI 的空间计数，提供表格、图表、地图和执行历史；原有分析入口保留。
4. 用边界点、重复业务 ID、零匹配、空类别、带引号字段和错误终态样例验证，再做构建与差异审阅。

## 首条链路的实现决策

首个正式算子为 `spatial_pivot@1`：面图层包含点图层，按目标要素和可选 POI 类别计数。计数使用数据库主键，业务 `id` 或名称重复不会合并目标；无匹配目标仍保留为 0。边界点是否计入由参数明确指定，重叠区域允许多重归属。

首条链路直接使用 PostGIS 执行确定性空间 SQL，Node 通过异步数据库调用调度有并发上限的任务，不生成或执行 Python。沿用已有数据表，并新增分析与结果表；源数据不回写。Python 引擎继续服务原有专业模型，后续迁移栅格或专业模型时再接入独立 Python Worker，避免首轮同时引入第二套队列和算法实现。

提交 Run 时在 repeatable-read 事务中固定输入指纹；执行前核对指纹，计算与结果登记也在一致读取事务中完成。重复执行需要相同输入指纹，否则明确拒绝重放。指纹用于检测变更，不冒充可恢复的历史数据快照。结果保存包含目标几何的独立产物，源数据后续编辑不改变既有结果。

本轮仅做增量建表，不删除或重命名现有表；当前未提交内容和论文素材保留。后续完整 DatasetVersion 存储和可恢复输入快照作为下一阶段工作。

## 已完成的基础修复

- 数据缓存改用文件 ID，增加分页响应过期保护；图层元数据未加载时暂缓渲染，分页更新不再重建全部额外图层。
- AI 的 NDJSON 协议独立解析，HTTP 错误、服务端错误、无效 JSON、断流和缺失结果均可显示为失败。
- 属性透视迁出旧控制器，字段通过 SQL 参数绑定；保留原有聚合类型，修复合法 0 与空值分类冲突。
- 旧计算重试使用明确成功标志，修复空数组误入成功路径；绘图重试使用修复后的代码。
- Python 读取复用已有连接；旧 AI schema 摘要改为完整字段集合；注册模型名增加路径字符校验。
- LLM 客户端延迟创建，不再强制使用机器特定代理；无 AI 密钥时可正常启动并运行确定性分析。数据库、端口和 Python API 可配置。
- 新任务连接失效会销毁并回收，断线恢复后任务进入明确失败终态，其他功能继续服务。
